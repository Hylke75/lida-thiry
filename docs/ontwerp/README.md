# Lida Thiry redesign — HTML prototype

Open `index.html` direct in een browser om de statische demo te bekijken. De demo laadt Google Fonts en tijdelijke foto’s extern, dus een internetverbinding is nodig.

Bestanden:
- `index.html` — complete homepage
- `styles.css` — design tokens + responsive styling
- `script.js` — mobiele navigatie + jaartal
- `HUISSTIJL-HANDBOEK.md` — merk- en implementatieregels
- `CLAUDE-CODE-INSTRUCTIE.md` — kant-en-klare developer briefing
- `PHOTO-SOURCES.md` — tijdelijke beeldbronnen

Voor productie: vervang vooral hero/Over Lida door echte fotografie van Lida en koppel alle demo-links aan bestaande routes.
